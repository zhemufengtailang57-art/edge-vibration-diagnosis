## 三、电源树

```
  12V DC (DC005)
      │
      ├─ F2: SMD1206-200-16 自恢复保险丝
      │
      ├─ Q1: AO3401A PMOS 电源开关（R1 10kΩ 上拉栅极）
      │
      └─── VCC_12V ──┬──────────────────────────┐
                     │                          │
              U1: MP2315GJ-Z              U8: HT7150
              (同步降压, 2A)              (LDO)
                     │                          │
                  VCC_3V3                    VCC_5V
              (数字 / 模拟 / 传感器)      (RS485 / 蜂鸣器)
```

- 输入端 100µF 电解 + 100nF 陶瓷去耦，抑制电机启停的电流冲击
- 3.3V 侧按 VCC / VDDA / VCAP 分区去耦，模拟供电独立走线
- RS485 与蜂鸣器走 5V，避免电机噪声串扰数字域

## 四、设计要点

**1. 电源与电机隔离**
TB6612 的电机供电（VM）与逻辑供电（VCC）分开走线，各自独立去耦（C32/C33、C34）。电机是大电流感性负载，启停瞬间的反电动势容易通过电源串扰到 MCU，分区去耦是最直接的抑制手段。

**2. RS485 自动方向**
选用 MAX13487EESA 而非传统的 MAX3485 + DE 控制线方案。前者内置自动方向控制，省去一路 GPIO 和软件切换时序，代价是**波特率受内部超时限制**——实测降到 57600 会导致帧尾被提前撤销，因此固件锁定 115200（详见 `docs/调试踩坑记录.docx`）。

**3. 传感器接线端子化**
ADXL345 与 DS18B20 均通过端子（DB125-2.54-8P、WJ500V-5.08-03P）外接，而非直接焊在板上。振动传感器需要贴装在电机壳体上，走线长度和位置直接影响信号质量，端子化便于现场调整。

**4. 磁珠隔离电源**
ADXL345 供电串入 BLM18AG601SN1D 磁珠（600Ω@100MHz），抑制高频噪声从数字电源耦合进加速度计——振动信号幅度在 mG 量级，电源纹波会直接污染测量结果。
